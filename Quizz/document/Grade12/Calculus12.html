Easy Questions

Medium Questions

10. Find the partial derivative of f(x, y) = x² + 3xy + y² with respect to y.

12. Evaluate ∫ x ln(x) dx using integration by parts.



13. Find the divergence of the vector field F = (x², y², z²).



14. Find the Jacobian determinant of f(x, y) = (x² + y, xy).
